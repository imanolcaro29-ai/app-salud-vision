De Supabase a Vercel,
sin escribir código.

Este asistente prepara los seis valores que vas a copiar en Vercel. Abrilo después de extraer el ZIP completo.

Los valores se preparan en tu equipo. Esta página no se conecta a internet ni guarda contraseñas. Copialos sólo en los campos de configuración de Vercel.

1. Completá la conexión y tu cuenta

Supabase → tu proyecto → Connect → Transaction pooler. Es la que elegiste al crear el proyecto. Si la conexión ya la incluye correctamente, podés dejar este campo vacío. Entre 12 y 128 caracteres. Guardala para ingresar.
Ya configuré esta base anteriormente

Si estás actualizando, conservá el secreto original. Uno nuevo no puede descifrar registros anteriores.

2. Copiá los valores en Vercel

En Environment Variables, agregá cada nombre con su valor. Elegí el entorno Production.

Conservá una copia protegida de DATA_SECRET. Vas a necesitar el mismo valor para recuperar la base o cambiar de alojamiento.

Después presioná Deploy, o Redeploy si el proyecto ya estaba creado. Ingresá con el correo y la contraseña que elegiste arriba.

La base se prepara antes con supabase/01_esquema.sql. La guía completa está en EMPEZAR_AQUI.md.
